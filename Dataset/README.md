# Dataset

`bangla_fake_news.csv` is the Bangla news dataset used by the research evaluation. It contains the columns `Category`, `headline`, `content`, and `label`.

The accompanying manuscript describes it as a public Kaggle Bangla fake-news dataset covering education, national, international, sports, politics, technology, finance, and miscellaneous reporting. The original download URL and upstream license were not recorded in this project, so users should verify the source terms before redistributing or using the data beyond academic reproducibility.

The file is committed because it is required to reproduce the published evaluation. GitHub does not render it in diffs because of its size; analysis scripts read it directly from this directory.

Do not add private uploads, claim records, or documents containing personal information to this folder.
